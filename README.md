An alarm clock that rings at 6am on a Saturday morning gets
exactly what it deserves: one line of roast. It is the only thing
in its owner's life that shows up early, on time, and completely
unwanted -- and even the ex had the decency to be late.

> 6am on a Saturday. My alarm clock is the only thing in my life that shows up early, on time, and completely unwanted — even my ex had the decency to be late.

## Run it

```sh
python3 main.py
```

This writes the entry line to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`).

Deterministic: Python 3 standard library only, no network, no
randomness, no clock, no input. The same line comes out every run.
